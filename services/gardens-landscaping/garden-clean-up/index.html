Garden Clean Up in Perth: Common Questions

Does a garden clean up include green waste removal?

Green waste collection and disposal need to be included in the agreed scope. Describe the likely volume, the material to cut back and access from the garden to the collection point.

Can garden tidying and small outdoor repairs be discussed together?

List both sets of tasks so each can be assessed. Weeding and manageable cutbacks are garden work; damaged fences or structures need their own checks before a combined scope can be confirmed.

What if there is old building debris among the plants?

Mention it before the clean up and leave suspect material untouched. Hazardous waste or potentially asbestos-containing debris requires assessment outside routine green waste handling.
