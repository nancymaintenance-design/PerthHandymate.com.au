Window Installation in Perth: Common Questions

What work is typically included in Window Installation?

Window installation covers measuring and fitting replacement or new window units while addressing openings, flashings, seals and finishes.

  • Measure the structural opening and select a compatible window configuration
  • Remove and replace an existing unit within an agreed scope
  • Install flashings, seals and trims appropriate to the wall system
What information helps confirm the scope?

Clear property information helps identify the appropriate pathway and site-specific constraints before work is arranged.

  • Opening measurements, wall construction and storey level
  • Photos inside and outside, including sills and surrounding finishes
  • Frame material, glazing, opening style and performance preferences
Are there safety, licensing or suitability issues to consider?

Glazing, upper-storey access and changes to structural openings require specialist controls; energy, bushfire or heritage requirements may affect product selection.

Requirements depend on the actual task, property and location, so they are checked before work proceeds.
